## 5. 在 onSelectTool 方法中添加检查

```javascript
onSelectTool(e) {
  const tool = e.currentTarget.dataset.tool;
  
  // 检查是否在背景图层，且选择的是绘图工具
  if (this.data.activeLayer === 'background' && 
      ['pen', 'eraser', 'fill', 'picker'].includes(tool)) {
    wx.showToast({ title: '背景图层无法使用绘图工具', icon: 'none', duration: 1500 });
    return;
  }
  
  this.setData({ tool });
  
  // 切换到拖拽工具时，显示提示
  if (tool === 'drag') {
    wx.showToast({ title: '拖拽模式：移动画布', icon: 'none', duration: 1500 });
  }
  
  if (this.data.showLeftToolbar) this.setData({ showLeftToolbar: false });
}
```

## 测试要点

1. **背景图显示**
   - 上传背景图后，背景图应该显示在画布下方
   - 画布应该变为透明，可以看到背景图

2. **背景图层切换**
   - 点击"背景"图标，切换到背景图层
   - 此时绘图工具应该被禁用

3. **锁定功能**（当前版本：背景图不跟随画布移动）
   - 拖拽画布时，背景图保持不动
   - 如需背景图跟随，需要将背景图放在 canvas-wrapper 内部

4. **画布透明度**
   - 无背景图时：画布底色纯白
   - 有背景图时：画布底色透明

## 注意事项

当前实现中，背景图是固定的，不会跟随画布移动缩放。如果需要背景图跟随画布移动缩放（锁定功能），需要将背景图移到 `canvas-wrapper` 内部，这样它会受到 transform 的影响。

如果需要实现锁定功能，可以这样修改 WXML：

```xml
<view class="canvas-wrapper" style="transform:translate({{canvasOffsetX}}px,{{canvasOffsetY}}px) scale({{canvasScale}});">
  <!-- 背景图层（跟随画布移动） -->
  <image 
    wx:if="{{backgroundImage && locked}}"
    class="background-layer-locked"
    src="{{backgroundImage}}"
    mode="aspectFit"
    style="width:{{canvasWidth}}px;height:{{canvasHeight}}px;"
  />
  
  <!-- 其他内容 -->
  ...
</view>
```

但这样会导致背景图也会被缩放，可能不是期望的效果。建议根据实际需求调整。
